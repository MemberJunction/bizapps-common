# COM-WORLD photos

`People.PhotoURL` is filled by `WorldAvatarURL(email)`.

These are **not** photographs of real people and **not** scraped stock photos.

| Piece | License | Source |
|---|---|---|
| Avatar artwork (`lorelei`) | [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (Lisa Wischofsky, remixed by DiceBear) | [DiceBear licenses](https://www.dicebear.com/licenses/) |
| HTTP API that serves the PNG | MIT | `https://api.dicebear.com/9.x/lorelei/png?seed=…` |

Seed is the person's `com-world.test` email, so the same face is stable across Common, Committees, and Secure Messaging.
